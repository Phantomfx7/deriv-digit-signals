# Digit Signals — Deriv Volatility Tools

A local dashboard for reading last-digit statistics on Deriv's synthetic
volatility indices, built as tabs:

- **Matches / Differs** — most/least frequent digit over a rolling window
- **Even / Odd** — even/odd split plus current & longest streak
- **Digits Over/Under** — % of ticks above/below/equal to a chosen digit threshold

Data comes straight from Deriv's public WebSocket API
(`wss://ws.derivws.com/websockets/v3`) — no login or API key required for
live tick data.

## Run it

You need [Node.js](https://nodejs.org) installed (18+ recommended).

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

### If you see "Symbol ... is invalid" errors

This happens even on rock-solid symbols like `R_100` — it's not about the
symbol code, it's the shared public `app_id=1089` this app falls back to
by default. That id is meant for quick testing and Deriv can throttle or
restrict it without notice. Fix:

1. Register a free app_id at https://developers.deriv.com/docs/app-registration
   (use `http://localhost:5173` as the redirect URI — you don't need
   trading permissions for this app, it's read-only market data)
2. Copy `.env.example` to `.env` and paste your app_id in:
   ```
   VITE_DERIV_APP_ID=12345
   ```
3. Restart `npm run dev` (Vite only reads `.env` on startup)

## Project structure

```
index.html              shared page shell (header, tab nav, digit tape)
src/
  main.js               tab router + wires header/tape to shared state
  store.js               single source of truth: rolling digit buffer, symbol, status
  deriv.js               the actual WebSocket connection to Deriv
  style.css               shared design tokens/styles
  tabs/
    matchesDiffers.js    Matches/Differs tab
    evenOdd.js            Even/Odd tab
    digits.js             Digits Over/Under tab
```

All three tabs read from the same `store.js` buffer, so switching the
market or the tab never re-opens the socket — there's exactly one live
connection for the whole app.

## Adding a new tab

1. Create `src/tabs/yourTool.js` exporting a `mount(container)` function
   that renders into `container` and returns an `unmount` cleanup function.
   Use `subscribe` and `lastDigits(n)` from `../store.js` to read live data.
2. Import it in `src/main.js` and add it to the `tabs` object.
3. Add a `<button class="tab-btn" data-tab="your-id">Your Tool</button>`
   to the `<nav class="tabs">` in `index.html`.

## Going further

- **Your own app_id**: this uses Deriv's public demo `app_id=1089`, which
  is fine for read-only tick streaming. If you add real trading (placing
  buy/sell contracts, needs OAuth), register your own app id at
  https://api.deriv.com/dashboard and swap it into `src/deriv.js`.
- **Backtesting**: the rolling buffer in `store.js` currently keeps the
  last 500 ticks in memory; persisting them (e.g. to IndexedDB) would let
  you backtest a rule like "trade the least-frequent digit" against
  history.

## A note on what this actually tells you

Deriv's volatility indices are generated by an audited random number
generator, and each tick's last digit is designed to be statistically
independent of the ones before it. The percentages here describe what
already happened in your sample window — they're a live data view, not
a predictive signal. Treat any "hot" or "cold" digit accordingly.
